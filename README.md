# Berserk Adventure

A 2D side-scroller action game made with Godot 4.

## About
Battle through enemies, collect set items to boost stats, and fight bosses. Every item changes your animations and abilities. Collect the full set to unlock your true power.

## Features (WIP)
- Side-scrolling combat with camera follow
- Inventory system with set bonuses
- Dynamic animations based on equipped items
- Boss fights with attack patterns
- Final mega boss encounter
